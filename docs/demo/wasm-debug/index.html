Debug this Wasm demo in Chrome
  1. Install Google Chrome and the C/C++ DevTools Support (DWARF) extension.
  2. Open DevTools with F12 or Ctrl+Shift+I, then select the Sources panel.
  3. Expand the page's Wasm source and open main.hike.
  4. Set a breakpoint on a Hike source line, then click a demo button. Use Resume, Step over, and Step into to inspect local variables and return values.
